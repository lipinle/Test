# Survival Flight — Addon บินได้ในโหมดเอาชีวิตรอด (Minecraft Bedrock / มือถือ)

ถือ **ขนนก (Feather)** แล้วกดใช้ เพื่อเปิด/ปิดการบินในโหมด Survival

## ขั้นตอนการติดตั้งบนมือถือ

1. ดาวน์โหลดไฟล์ `SurvivalFlight.mcaddon` ลงมือถือ
2. แตะเปิดไฟล์ → เลือกเปิดด้วย Minecraft → เกมจะขึ้นว่า "Import Started… / Successfully imported"
   - ถ้าแตะแล้วไม่ขึ้น (บาง iPhone): ใช้แอป Files → แชร์ → เลือก Minecraft
3. สร้างโลกใหม่ หรือแก้ไขโลกเดิม → **Behavior Packs** → **Available** → เลือก *Survival Flight* → **Activate**
4. (ไม่บังคับ แต่แนะนำ) **Game Settings → Cheats → เปิด Education Edition**
   เพื่อให้บินได้เหมือนโหมดสร้างสรรค์จริง ๆ
5. เข้าโลก หาขนนก (ฆ่าไก่) แล้วกดใช้

> ต้องใช้ Minecraft Bedrock เวอร์ชัน 1.21.90 ขึ้นไป ไม่ต้องเปิด Experiments ใด ๆ

## วิธีบิน

| การกระทำ | ผลลัพธ์ |
|---|---|
| ถือขนนก แล้วแตะค้าง (PC: คลิกขวา) | เปิด / ปิดการบิน |
| **เปิด Education Edition ไว้** | แตะปุ่มกระโดด 2 ครั้ง บินเหมือนโหมดสร้างสรรค์ |
| **ไม่ได้เปิด Education Edition** | กดกระโดดค้าง = บินขึ้น, กดย่อ = บินลง, ไม่กด = ลอยนิ่ง, จอยสติ๊ก = บินไปทางที่มอง, วิ่ง = บินเร็วขึ้น |

- ปิดการบินกลางอากาศจะได้ Slow Falling 5 วินาที ไม่ตกตาย
- สถานะการบินจะถูกจำไว้ ออกแล้วเข้าเกมใหม่/ตายแล้วเกิดใหม่ก็ยังบินได้

## โครงสร้างไฟล์

```
SurvivalFlight_BP/
├── manifest.json      ข้อมูล pack + ประกาศใช้ Script API (@minecraft/server 2.0.0)
├── pack_icon.png      ไอคอน
└── scripts/main.js    โค้ดการบินทั้งหมด
build.sh               แพ็กเป็น SurvivalFlight.mcaddon
```

## หลักการทำงาน (คิดทีละขั้น)

1. **เลือกวิธี** — Bedrock ไม่มีคำสั่งให้ Survival บินได้ตรง ๆ ยกเว้น `/ability mayfly`
   ซึ่งใช้ได้เฉพาะเมื่อเปิด Education Edition จึงทำ 2 โหมด
2. **ตรวจโหมด** — ตอนเปิดการบิน สคริปต์ลองรัน `ability @s mayfly true`
   ถ้าสำเร็จใช้โหมด Native ถ้าล้มเหลวใช้โหมด Scripted
3. **โหมด Scripted** — ทุก tick อ่านปุ่มกระโดด/ย่อ และจอยสติ๊ก (`inputInfo.getMovementVector()`)
   แปลงเป็นทิศตามมุมกล้อง แล้วตั้งความเร็วด้วย `applyKnockback()`
4. **กันตกตาย** — ใส่ Slow Falling แบบไม่มี particle ระหว่างบิน และหลังปิดการบิน
5. **จำสถานะ** — เก็บใน Dynamic Property ของผู้เล่น แล้วคืนค่าเมื่อเกิดใหม่

## ปรับแต่ง

แก้ค่าด้านบนของ `scripts/main.js` เช่น `TOGGLE_ITEM`, `FLY_SPEED`, `SPRINT_SPEED`, `VERTICAL_SPEED`
แล้วรัน `./build.sh` เพื่อสร้างไฟล์ `.mcaddon` ใหม่

# Smelted Ore Blocks — ขุดแร่ได้บล็อกแร่ที่เผาแล้ว (Minecraft Bedrock / มือถือ)

ขุดแร่ด้วยเครื่องมือที่ถูกต้อง แล้วจะได้ **บล็อก** ของแร่ที่เผาแล้วแทนของที่ดรอปตามปกติ

| แร่ (รวม Deepslate) | ได้ |
|---|---|
| แร่ถ่านหิน | บล็อกถ่านหิน |
| แร่เหล็ก | บล็อกเหล็ก |
| แร่ทองแดง | บล็อกทองแดง |
| แร่ทอง / แร่ทองเนเธอร์ | บล็อกทอง |
| แร่เรดสโตน | บล็อกเรดสโตน |
| แร่ลาพิส | บล็อกลาพิส |
| แร่เพชร | บล็อกเพชร |
| แร่มรกต | บล็อกมรกต |
| แร่ควอตซ์เนเธอร์ | บล็อกควอตซ์ |

## ติดตั้ง

1. ดาวน์โหลด `SmeltedOreBlocks.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *Smelted Ore Blocks* → **Activate**
3. เข้าโลกแล้วขุดแร่ได้เลย

> ต้องใช้ Minecraft Bedrock 1.21.90 ขึ้นไป ไม่ต้องเปิด Experiments

## รายละเอียด

- ยังต้องใช้เครื่องมือที่ถูกต้องเหมือนเดิม (เช่น แร่เพชรต้องใช้อีเตอร์เหล็กขึ้นไป) ใช้ผิดจะไม่ได้อะไร
- ยังได้ XP และเครื่องมือยังสึกตามปกติ
- ขุดด้วย **Silk Touch** ยังได้ตัวแร่เหมือนเดิม
- Fortune ไม่มีผล ได้ 1 บล็อกต่อแร่ 1 ก้อน
- โหมดสร้างสรรค์จะไม่ดรอปอะไร

## ปรับแต่ง

แก้ค่าด้านบนของ `SmeltedOreBlocks_BP/scripts/main.js`:
`ORE_TO_BLOCK` (แร่ → บล็อกที่ได้), `BLOCKS_PER_ORE`, `KEEP_SILK_TOUCH`
แล้วรัน `./build.sh` เพื่อสร้าง `.mcaddon` ใหม่

# Gear Effects — สวมเกราะ / ถือไอเท็ม แล้วได้เอฟเฟกต์ (Minecraft Bedrock / มือถือ)

## ติดตั้ง

1. ดาวน์โหลด `GearEffects.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *Gear Effects* → **Activate**

> ต้องใช้ Minecraft Bedrock 1.21.90 ขึ้นไป ไม่ต้องเปิด Experiments

## เซ็ตเกราะ (นับชิ้นที่เป็นวัสดุเดียวกัน)

| เกราะ | ใส่ 2 ชิ้นขึ้นไป | ใส่ครบ 4 ชิ้น |
|---|---|---|
| หนัง | ความเร็ว I | + กระโดดสูง I |
| โซ่ | ความเร็ว I | + ขุดเร็ว I |
| ทองแดง | ขุดเร็ว I | + ต้านทาน I |
| ทอง | ขุดเร็ว I | + ฟื้นฟูเลือด I |
| เหล็ก | ต้านทาน I | + พลังโจมตี I |
| เพชร | ต้านทาน I | + พลังโจมตี I, ฟื้นฟูเลือด I |
| เนเธอไรต์ | ต้านทาน I, กันไฟ | ต้านทาน II, พลังโจมตี II, ฟื้นฟูเลือด I, กันไฟ |
| หมวกกระดองเต่า (1 ชิ้น) | หายใจใต้น้ำ, มองในที่มืด | |

## ไอเท็มในมือ (มือหลักหรือมือรอง)

| ไอเท็ม | เอฟเฟกต์ |
|---|---|
| ดาบ, ขวาน | พลังโจมตี I (เพชร/เนเธอไรต์ = II) |
| อีเตอร์, พลั่ว, จอบ | ขุดเร็ว I (เพชร/เนเธอไรต์ = II) |
| ธนู, หน้าไม้, น้ำตาล | ความเร็ว I |
| ตรีศูล, หัวใจแห่งท้องทะเล | พลังคอนดูอิต |
| กระบอง (Mace) | กระโดดสูง II |
| เท้ากระต่าย | กระโดดสูง I |
| โล่ | ต้านทาน I |
| เบ็ดตกปลา, เปลือกหอยนอติลุส | หายใจใต้น้ำ |
| คบเพลิง, ตะเกียง, กล้องส่องทางไกล, ตาเอนเดอร์ | มองในที่มืด |
| ขนนก | ตกช้า |
| แท่งเบลซ, ครีมแมกมา | กันไฟ |
| โทเท็มแห่งความเป็นอมตะ, แตงโมทอง | ฟื้นฟูเลือด I |

- ถ้าได้เอฟเฟกต์เดียวกันจากหลายแหล่ง จะใช้ระดับที่สูงที่สุด
- ถอดเกราะ / เปลี่ยนของในมือ เอฟเฟกต์จะหายภายใน 1 วินาที
- ไม่ลบเอฟเฟกต์จากยาหรือบีคอนที่แรงกว่าหรือนานกว่า
- เมื่อเอฟเฟกต์เปลี่ยนจะมีข้อความบอกเหนือแถบไอเท็ม

## ปรับแต่ง

# Sword Sweep — ดาบตีกวาดเหมือน PC (Minecraft Bedrock / มือถือ)

ถือดาบแล้ว**แตะตี**ตรงไหนก็ได้ (ฟันอากาศก็ออก) ระบบจะกวาดฟันศัตรูทุกตัวที่อยู่ข้างหน้าเป็นรูปพัด **ไม่ต้องเล็งให้โดนตัว**
ดาบยิ่ง tier สูง ยิ่งกวาดได้**ไกลและกว้างขึ้น** และ**ดาบเนเธอไรท์ฟันได้รอบตัว 360°**
และยังใช้ดาบขุด/ทุบบล็อกได้ตามปกติ

## ติดตั้ง

1. ดาวน์โหลด `SwordSweep.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *Sword Sweep* → **Activate**
3. เข้าโลก ถือดาบ แล้วแตะจอตีได้เลย

> ต้องใช้ Minecraft Bedrock **1.26.10 ขึ้นไป** (ใช้ Script API `@minecraft/server` 2.5.0) ไม่ต้องเปิด Experiments

## การทำงาน

| การกระทำ | ผลลัพธ์ |
|---|---|
| แตะตีอากาศ (ไม่โดนอะไร) | กวาดข้างหน้า: ตัวที่อยู่ตรงหน้าที่สุดโดนดาเมจเต็ม ตัวอื่นโดนดาเมจกวาด |
| แตะตีโดนมอนตรง ๆ | ตัวที่โดนรับดาเมจปกติจากเกม ตัวรอบ ๆ โดนดาเมจกวาด |
| แตะค้าง / ขุดบล็อก | ขุดบล็อกตามปกติ ไม่กวาด |
| หันไปมองบล็อกที่อยู่ใกล้กว่ามอน แล้วแตะ | ถือว่ากำลังขุด ไม่กวาด |

- ระยะและความกว้างของการกวาดขึ้นกับชนิดดาบ ตีทะลุกำแพงไม่ได้:

| ดาบ | ดาเมจ | ระยะกวาด | ความกว้าง |
|---|---|---|---|
| ไม้ | 5 | 3 บล็อก | 100° |
| ทอง | 5 | 3.5 บล็อก | 120° |
| หิน | 6 | 3.5 บล็อก | 120° |
| ทองแดง | 6 | 4 บล็อก | 140° |
| เหล็ก | 7 | 4.5 บล็อก | 160° |
| เพชร | 8 | 5 บล็อก | 200° (ถึงด้านข้างลำตัว) |
| **เนเธอไรท์** | 9 | **6 บล็อก** | **360° ฟันรอบตัว** |
| ดาบจาก addon อื่น | 6 | 3.5 บล็อก | 120° |

- ดาเมจคิดจากชนิดดาบ + Sharpness + ยาพลังโจมตี/อ่อนแรง และ Fire Aspect ทำให้ไฟติด
- ดาเมจกวาด = 1 + 50% ของดาเมจดาบ (PC ได้แค่ 1 ถ้าไม่มี Sweeping Edge ซึ่ง Bedrock ไม่มีเอนชานต์นี้)
- กวาดได้ทุก 0.6 วินาที ใกล้กับความเร็วดาบใน PC
- ไม่โดนผู้เล่นคนอื่น, สัตว์เลี้ยงของตัวเอง, ไอเท็ม, อาร์เมอร์สแตนด์
- ใช้ได้กับดาบทุกชนิด รวมถึงดาบจาก addon อื่นที่ชื่อลงท้ายด้วย `_sword` หรือมี tag `minecraft:is_sword`
- ดาบสึกเพิ่ม 1 เมื่อกวาดโดนศัตรูโดยไม่ได้ตีโดนตรง ๆ (คิด Unbreaking ด้วย ไม่สึกในโหมดสร้างสรรค์)

## ปรับแต่ง

แก้ค่าด้านบนของ `SwordSweep_BP/scripts/main.js`:
`SWORD_TIERS` (ดาเมจ / ระยะ / ความกว้างของดาบแต่ละชนิด), `DEFAULT_TIER`, `SWEEP_DAMAGE_RATIO`, `COOLDOWN_TICKS`, `KNOCKBACK`, `HIT_PLAYERS`, `HIT_OWN_PETS`
แล้วรัน `./build.sh` เพื่อสร้าง `.mcaddon` ใหม่

# RPG Levels — ระบบเลเวลตัวละครแบบละเอียด (Minecraft Bedrock / มือถือ)

ระบบ RPG เต็มรูปแบบ: **เลเวลตัวละคร 1–100**, **ค่าสถานะ 6 ตัว**, **ความชำนาญอาวุธ/อุปกรณ์ 8 ชนิด** (ถึงขั้นได้เอฟเฟกต์พิเศษ)
และ **สกิลพิเศษ 20 สกิล** ที่ปลดล็อกตามเลเวล แล้ว **เปิด/ปิดเองได้** เช่น บินได้ แม่เหล็ก ขุดแร่ทั้งสาย ตัดต้นไม้ทั้งต้น มองในที่มืด กันไฟ

## ติดตั้ง

1. ดาวน์โหลด `RPGLevels.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft (มีทั้ง Behavior + Resource pack ในไฟล์เดียว)
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *RPG Levels* → **Activate** (Resource pack จะเปิดให้อัตโนมัติ)
3. (แนะนำ) **Game Settings → Cheats → เปิด Education Edition** เพื่อให้สกิลบินได้เหมือนโหมดสร้างสรรค์
4. เข้าโลก จะได้ **สมุดสถานะ RPG** ฟรี → ถือแล้วแตะใช้ (PC: คลิกขวา) เพื่อเปิดเมนู

> ต้องใช้ Minecraft Bedrock 1.21.90 ขึ้นไป ไม่ต้องเปิด Experiments
> ไม่ควรเปิดคู่กับ *Survival Flight* (ทั้งคู่คุมการบินเหมือนกัน)

## เมนูสมุดสถานะ

| ปุ่ม | ทำอะไร |
|---|---|
| ข้อมูลตัวละคร | ดูค่าสถานะ + ผลที่ได้จริง (ดาเมจ, % หลบ, % คริ ฯลฯ), ความชำนาญ, สกิลที่เปิดอยู่ |
| อัพค่าสถานะ | ใช้แต้มอัพ STR / VIT / DEF / AGI / DEX / LUK (เลื่อนแถบเลือกจำนวน) และรีเซ็ตแต้ม (ใช้ 10 เลเวล XP) |
| ความชำนาญอาวุธ/อุปกรณ์ | ดูเลเวลและเอฟเฟกต์ที่ปลดล็อกของอุปกรณ์แต่ละชนิด |
| สกิลพิเศษ | แตะเพื่อเปิด/ปิดทีละสกิล หรือเปิด/ปิดทั้งหมด |
| ตั้งค่า | แถบ XP, ขุดแร่/ตัดไม้ต้องย่อตัวไหม, ทำลายใบไม้ไหม, ระยะแม่เหล็ก |
| ผู้ดูแลโลก | (เฉพาะคนแรกที่เข้าโลก หรือมีแท็ก `rpg_admin`) ตัวคูณ XP, โชว์เลเวลเหนือชื่อ, ตั้งเลเวล/ล้างข้อมูลผู้เล่น |

สมุดหาย → คราฟใหม่: **หนังสือ + ลาพิส ลาซูลี** (ไม่มีรูปแบบ)

## เลเวลตัวละคร

- รับ XP จาก: ฆ่ามอน (ซอมบี้ 15, เอนเดอร์แมน 30, วอร์เดน 500, มังกร 3000), ขุดแร่ (เพชร 25, เศษโบราณ 50), ตัดไม้ 2, เก็บพืชที่โตแล้ว 3, ขุดบล็อกทั่วไป 0.3
- เลเวลอัพได้ **3 แต้มสถานะ** และทุก 10 เลเวลได้เพิ่มอีก **5 แต้ม**
- มีฉายาตามเลเวล (มือใหม่ → นักผจญภัย → นักรบ → ผู้กล้า → ยอดฝีมือ → ปรมาจารย์ → ตำนาน → เทพเจ้า) และโชว์ `[Lv.xx]` เหนือชื่อ
- ตายไม่เสียเลเวล ข้อมูลเก็บในตัวผู้เล่น (ออก-เข้าเกมใหม่ยังอยู่)

# Smart Mobs — มอนสเตอร์เก่งขึ้นตามวันเวลาในเกม (Minecraft Bedrock / มือถือ)

ยิ่งเล่นนาน มอนสเตอร์ยิ่งโหด: **เกราะดีขึ้น อาวุธดีขึ้น มีเอนชานต์ มีเอฟเฟกต์** และ **AI ฉลาดขึ้น**
ตามจำนวนวันที่ผ่านไปในโลก (นับจาก `world.getDay()` — นอนข้ามคืนก็นับเป็นวันด้วย)
พร้อม **บอส 5 ตัว** ที่มีท่าพิเศษ และดรอป **ไอเท็มในตำนาน** ที่หาที่อื่นไม่ได้

## ติดตั้ง

1. ดาวน์โหลด `SmartMobs.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft (มีทั้ง Behavior + Resource pack ในไฟล์เดียว)
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *Smart Mobs* → **Activate** (Resource pack จะเปิดให้อัตโนมัติ)
3. เข้าโลกแล้วเล่นตามปกติ — ตอนเข้าเกมจะขึ้นข้อความบอกวันและระดับปัจจุบัน

> ต้องใช้ Minecraft Bedrock 1.21.90 ขึ้นไป ไม่ต้องเปิด Experiments
> ใช้กับโลกเดิมได้ (นับวันต่อจากที่เล่นอยู่) และเปิดคู่กับ addon อื่นในชุดนี้ได้

## ระดับความโหด

| ระดับ | ตั้งแต่วันที่ | เกราะ (โอกาสต่อชิ้น) | อาวุธ | เอนชานต์สูงสุด | เอฟเฟกต์ | AI ที่ได้เพิ่ม |
|---|---|---|---|---|---|---|
| 0 ปกติ | 0 | – | – | – | – | – |
| 1 ตื่นตัว | 3 | หนัง/ทอง 20% | ดาบไม้/หิน | – | – | พุ่งกระโจน, เรียกพวก (8 บล็อก) |
| 2 นักรบ | 7 | หนัง–เหล็ก 35% | ดาบหิน/เหล็ก, ขวานหิน | I | – | ถอยหนีแล้วยิง, หลบข้าง |
| 3 ทหาร | 14 | โซ่/เหล็ก 50% | ดาบ/ขวานเหล็ก | II | ความเร็ว | ล่าเป็นฝูง, ฮึดสู้ตอนเลือดน้อย, Creeper ชาร์จ |
| 4 อัศวิน | 21 | เหล็ก/เพชร 65% | ดาบเพชร | III | + พลังโจมตี, เลือดเพิ่ม | กระโดดหาคนต่อเสา |
| 5 ยอดฝีมือ | 30 | เพชร 80% | ดาบ/ขวานเพชร | IV | + ต้านทาน | ทุกอย่างถี่และแรงขึ้น |
| 6 ราชันย์ | 45 | เพชร/เนเธอไรต์ 90% | เนเธอไรต์ | V | แรงขึ้น | 〃 |
| 7 ฝันร้าย | 60 | เพชร/เนเธอไรต์ 100% | เนเธอไรต์ 100% | V | แรงสุด | 〃 |

- มอนแต่ละตัวสุ่มของไม่เหมือนกัน มีโอกาส 5% เกิดเป็น **หัวหน้า** ที่ได้ของระดับถัดไป
- เมื่อขึ้นระดับใหม่ ทุกคนในโลกจะได้รับข้อความเตือน
- ใส่ของเฉพาะมอนที่**เกิดใหม่** มอนตัวเก่ายังเหมือนเดิม แต่ AI จะฉลาดขึ้นตามระดับปัจจุบันทุกตัว

## AI ที่ฉลาดขึ้น

| ท่า | ทำอะไร |
|---|---|
| พุ่งกระโจน | ซอมบี้/แมงมุม/Vindicator ที่หันมาไล่เรา จะกระโจนเข้าหาจากระยะ 3–7 บล็อก |
| กระโดดหาคนต่อเสา | ผู้เล่นต่อเสาหนีอยู่เหนือหัว 2–4 บล็อก มอนจะกระโดดสูงขึ้นไปตี |
| ถอยหนีแล้วยิง | Skeleton/Pillager ถอยหลังพร้อมเบี่ยงข้างเมื่อผู้เล่นเข้าใกล้ |
| หลบข้าง | โดนตีแล้วกระโดดหลบไปด้านข้าง |
| เรียกพวก | ตีมอนตัวหนึ่ง มอนที่อยู่รอบ ๆ (สูงสุด 8 ตัว) จะหันมารุมเรา |
| ล่าเป็นฝูง | มอนตีโดนเรา พวกที่อยู่ใกล้จะเข้ามาช่วย |
| ฮึดสู้ | เลือดเหลือต่ำกว่า 30% ได้ฟื้นเลือดและวิ่งเร็วขึ้นชั่วครู่ (ครั้งเดียว) |

- แมงมุมยังเป็นกลางตอนกลางวัน (ไม่พุ่ง ไม่ถูกเรียกรุม) และ Enderman/Zombified Piglin/Piglin ไม่ถูกเรียกรุม
- ผู้เล่นโหมดสร้างสรรค์/ผู้ชม จะไม่โดนท่า AI

## ของดรอป

ของที่สคริปต์ใส่ให้มีโอกาสดรอปแค่ **8.5%** และเป็นของมีรอยสึก กันฟาร์มเพชร/เนเธอไรต์ฟรี
(ของที่ผู้เล่นทิ้งเองไม่โดนลบ)

## บอส

ตั้งแต่ **วันที่ 7** (ระดับ 2) ตอนกลางคืน มอนที่เกิดใกล้ผู้เล่นมีโอกาสเล็กน้อยกลายเป็นบอส
(เกิดเองได้ไม่เกิน **1 ตัวต่อวันในเกม** และมีพร้อมกันไม่เกิน 2 ตัว) หรือเรียกเองด้วย **กะโหลกต้องสาป**

- ชื่อบอสพร้อมแถบเลือดลอยบนหัว และแสดงที่แถบด้านล่างจอเมื่ออยู่ใกล้
- เลือดเยอะ (120–200 คูณเพิ่มตามระดับ) ใส่เกราะเต็มชุดติดเอนชานต์ กันไฟ ไม่ไหม้แดด
- เลือดเหลือครึ่ง → **คลั่ง** เร็วขึ้น ตีแรงขึ้น ใช้ท่าถี่ขึ้น
- ไม่มีใครสู้ด้วย 30 วินาที → ค่อย ๆ ฟื้นเลือด

| บอส | เกิดจาก | ท่าพิเศษ | ตีโดนแล้วติด | ของเด่น |
|---|---|---|---|---|
| ราชาซอมบี้ | Zombie, Husk | ทุบพื้นกระแทกรอบตัว, กระโจนไกล, เรียกซอมบี้ | หิว | ดาบสังหารราชันย์ |
| จอมพลโครงกระดูก | Skeleton, Stray, Bogged | ยิงธนูชุด 5 ดอก, วาร์ปหนีเมื่อโดนประชิด, เรียก Stray | ช้า | คทาสายฟ้า, ไข่มุกมิติ |
| ราชินีแมงมุม | Spider, Cave Spider | พ่นใยดักขา, กระโจน, เรียกแมงมุมพิษ | พิษ | ไข่มุกมิติ, พลั่วไททัน |
| อัศวินวิเธอร์ | Wither Skeleton | พุ่งชาร์จ, ออร่าวิเธอร์, เรียกโครงกระดูกวิเธอร์ | วิเธอร์ | ขวานพิฆาต |
| จอมทัพอิลเลเจอร์ | Pillager, Vindicator | เขี้ยวอีโวเกอร์เป็นแนว, เรียก Vex, เป่าแตรบัฟพวก | อ่อนแรง | ขวานพิฆาต, ดาบ, คทา |

ฆ่าบอสได้: **เพชร 2–5** + XP เยอะ + มีโอกาสได้ เศษเนเธอไรต์, แอปเปิลทอง, Totem, แอปเปิลทองเอนชานต์ (3%), กะโหลกต้องสาป
และ **ไอเท็มในตำนาน** (โอกาส 4–20% ต่อชิ้นตามบอส เพิ่มอีก 10% ต่อระดับ) — ประกาศให้ทั้งโลกรู้เมื่อได้

## ไอเท็มในตำนาน (ดรอปจากบอสเท่านั้น)

# Mega Stack — ไอเท็มบนพื้นรวมกองได้ 10 ล้านชิ้น (Minecraft Bedrock / มือถือ)

ไอเท็มที่ตกบนพื้นจะ**ไม่ตันที่ 64 อีกต่อไป** ไอเท็มชนิดเดียวกันจะรวมเป็น**ไอเท็มชิ้นเดียว**บนพื้น
พร้อม**ป้ายโฮโลแกรมลอยบอกชื่อและจำนวน** สูงสุด **10,000,000 ชิ้นต่อกอง**

```
     Cobblestone
     x1,234,567
        [■]
```

## ติดตั้ง

1. ดาวน์โหลด `MegaStack.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *Mega Stack* → **Activate**
   (เกมจะเปิด Resource Pack *Mega Stack (Resources)* ให้อัตโนมัติ — ต้องมี เพราะเป็นตัวป้ายลอย)
3. เข้าโลก โยนของ / ขุด / ฟาร์มมอบ ได้เลย

> ต้องใช้ Minecraft Bedrock **1.26.10 ขึ้นไป** (ใช้ Script API `@minecraft/server` 2.5.0) ไม่ต้องเปิด Experiments

## การทำงาน

| สถานการณ์ | ผลลัพธ์ |
|---|---|
| ไอเท็มชนิดเดียวกันตกในระยะ **9 บล็อก** | กองเก่าวาปไปรวมกับ**กองใหม่** (มีเส้นแสงพุ่งไปหา + เสียงวาป) เหลือไอเท็มชิ้นเดียว |
| ทุกกองบนพื้น | มีป้ายชื่อไอเท็ม + จำนวน**ลอยขึ้นตลอดเวลา** ไม่ต้องเล็ง (สีเหลือง ≤ 1 สแต็ก, เขียว, ชมพู ≥ 10,000, ทอง ≥ 1,000,000) |
| เดินไปเก็บ | ได้ของเต็มกระเป๋าทันที ที่เหลือยังอยู่บนพื้นพร้อมตัวเลขที่ลดลง |
| ฮอปเปอร์ดูด / มอบเก็บ | ได้ไปทีละสแต็กตามปกติ ส่วนที่เหลือยังอยู่ในกอง |
| กองถึง 10,000,000 | กองนั้นหยุดรับ ของที่ตกเพิ่มจะเริ่มกองใหม่ |

- ไอเท็มจะรวมกันได้ต้อง**เหมือนกันทุกอย่าง** (ชื่อที่ตั้ง, lore, เอนชานต์ ฯลฯ — เกมเป็นคนเทียบให้)
- เครื่องมือ/อาวุธ/เกราะ (ซ้อนปกติไม่ได้) รวมกันได้ถ้าความทนทาน เอนชานต์ ชื่อ สีย้อม เหมือนกันหมด
- **ไม่รวม** กล่องชัลเกอร์, bundle, แผนที่, หนังสือที่เขียน, ยา, ธง, พลุ เพราะข้อมูลข้างในจะหาย
- ตกลาวา/ไฟ/กระบองเพชร หรือหมดเวลา (5 นาที) แบบไม่มีใครอยู่ใกล้ = หายทั้งกอง เหมือนเกมปกติ
- จำนวนในกองถูกบันทึกไว้กับตัวไอเท็ม ออกเกม/เข้าใหม่ก็ยังอยู่ครบ
- ชื่อบนป้ายแสดงเป็นภาษาอังกฤษจาก ID ไอเท็ม (Script API ดึงชื่อภาษาไทยของเกมไม่ได้) ยกเว้นไอเท็มที่ตั้งชื่อเองจะใช้ชื่อนั้น

## คำสั่ง (ต้องเปิดโกง)

| คำสั่ง | ผล |
|---|---|
| `/scriptevent ms:info` | ดูจำนวนกองและจำนวนไอเท็มทั้งหมดบนพื้น (เฉพาะพื้นที่ที่โหลดอยู่) |
| `/scriptevent ms:clear` | ลบไอเท็มบนพื้นทั้งหมด ใช้แทน `/kill @e[type=item]` (ถ้าใช้ `/kill` ตอนยืนใกล้กอง กองใหญ่จะเหลือส่วนที่เกินกลับมา) |

## ป้ายลอย (โฮโลแกรม)

ไอเท็มบนพื้นเป็น entity ที่ฝังในตัวเกม ตั้งให้ป้ายชื่อขึ้นตลอดไม่ได้ จึงสร้าง entity ป้ายแยก `ms:hologram`
ลอยอยู่เหนือแต่ละกอง:

- **Behavior Pack** (`entities/hologram.json`): `minecraft:nameable` → `always_show: true`, ไม่มีแรงโน้มถ่วง ไม่ชนอะไร
  hitbox เล็กมากจนตีไม่โดน ไม่รับดาเมจ ผลักไม่ได้
- **Resource Pack**: โมเดลว่าง + เท็กซ์เจอร์โปร่งใส เห็นแค่ตัวหนังสือ
- **สคริปต์**: กองไหนไม่มีป้ายก็สร้างให้ (จำ id กองไว้ในป้าย) ป้ายตามไอเท็ม**ทุก tick** (ลื่นตอนไอเท็มไหลน้ำ/ตก)
  แต่จะย้ายเฉพาะตอนไอเท็มขยับจริง กองที่อยู่นิ่งไม่ส่งข้อมูลเพิ่มเลย
  กองถูกรวม/หายไป → ลบป้ายทันที, กองถูกเก็บแล้ววางส่วนที่เหลือคืน → ย้ายป้ายเดิมไปให้กองใหม่ (ไม่กระพริบ)
  ป้ายที่ไม่มีเจ้าของเกิน 0.5 วินาที (เช่น ปิดเกมกลางคัน) จะถูกลบเอง
- ถ้าสร้างป้ายไม่ได้ (เช่น ไม่ได้เปิด Resource Pack) จะกลับไปใช้ป้ายชื่อบนตัวไอเท็มเหมือนเดิม (ขึ้นตอนเล็ง)

## หลักการทำงาน

1. ทุก 5 tick สแกนไอเท็มบนพื้น เก็บ "จำนวนทั้งหมด" ไว้ใน Dynamic Property ของ entity ไอเท็ม
   ตัว entity ถือของจริงแค่ไม่เกิน 1 สแต็ก ที่เหลือเป็นตัวเลข
2. เรียงจากกองใหม่สุด → กองเก่าที่ชนิดเดียวกันในระยะ 9 บล็อก ถูกบวกจำนวนเข้ากองใหม่แล้วลบทิ้ง
3. ผู้เล่นยืนใกล้กอง → ใส่ส่วนที่เกินเข้ากระเป๋าด้วย `container.addItem()` จนเต็ม
4. ของจริงในตัว entity ลดลง (โดนเก็บบางส่วน) → หักออกจากจำนวนรวม
5. entity ถูกเก็บไปทั้งตัว (`beforeEvents.entityRemove`) และมีผู้เล่น/มอบ/ฮอปเปอร์อยู่ใกล้ → วางส่วนที่เหลือกลับเป็นกองใหม่ที่เดิม
   ถ้าไม่มีอะไรอยู่ใกล้ (หมดเวลา, chunk ถูก unload) จะไม่วางคืน เพื่อกันของซ้ำ

## ปรับแต่ง

แก้ค่าด้านบนของ `MegaStack_BP/scripts/main.js`:
`MAX_STACK`, `MERGE_RADIUS`, `SCAN_INTERVAL`, `PICKUP_RADIUS`, `PICKUP_DELAY`, `MERGE_UNSTACKABLES`, `WARP_EFFECT`, `HOLOGRAM_HEIGHT`, `NEVER_MERGE_UNSTACKABLE`
แล้วรัน `./build.sh` เพื่อสร้าง `.mcaddon` ใหม่

# Spear Mastery — หอกเก่งขึ้น ไม่ต้องเล็ง (Minecraft Bedrock / มือถือ)

บนมือถือหอกเล็งยากและแรงไม่พอ addon นี้ทำให้หอก**ล็อกเป้าให้อัตโนมัติ** แค่หันไปทางศัตรูแล้วแตะตี
และเพิ่มสกิลใหม่ 4 อย่าง: **แทงทะลุ, พุ่งแทง, ขว้างหอกวิญญาณติดตามเป้า, ฝนหอก** และ **กระโดดปักหอกกระแทกพื้น**
ใช้ได้กับหอกทุกชนิด (ไม้ ทอง หิน ทองแดง เหล็ก เพชร เนเธอไรท์) และหอกจาก addon อื่นที่ชื่อลงท้ายด้วย `_spear`

## ติดตั้ง

1. ดาวน์โหลด `SpearMastery.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *Spear Mastery* → **Activate**
3. เข้าโลก ถือหอก แล้วหันไปหามอน

> ต้องใช้ Minecraft Bedrock **1.26.10 ขึ้นไป** (ใช้ Script API `@minecraft/server` 2.5.0) ไม่ต้องเปิด Experiments

## การควบคุม

| การกระทำ (ถือหอก) | สกิล |
|---|---|
| แค่ถือไว้ | **ล็อกเป้า** — เลือกมอนที่อยู่ใกล้กลางจอที่สุด (ไกลสุด 20 บล็อก) มีเครื่องหมายเหนือหัวเป้า และแถบบอกชื่อ/ระยะ/คูลดาวน์ |
| แตะตี (ไม่ต้องโดนตัว) | **แทงอัตโนมัติ** — แทงเป้าที่ล็อกไว้ ถ้าอยู่ในระยะแทง |
| แตะตี เมื่อเป้าไกลเกินระยะนิดหน่อย | **พุ่งแทง** — พุ่งเข้าไปหาเป้า (ไกลสุดระยะแทง +4 บล็อก) แล้วแทงเมื่อถึงตัว |
| ทุกการแทง | **แทงทะลุ** — ศัตรูที่อยู่แนวเดียวกันด้านหลังเป้า (3 บล็อก) โดน 60% |
| **ย่อ + แตะตี** | **ขว้างหอกวิญญาณ** — หอกแสงบินโค้งตามเป้าเอง โดนแล้วช้าลง 2 วินาที (คูลดาวน์ 3 วินาที) |
| **กดใช้ค้าง (ชาร์จหอก) 1 วินาทีแล้วปล่อย** หรือ **ย่อ + กดกระโดด** | **ฝนหอก** — หอกตกจากฟ้าใส่ศัตรูรอบเป้าในรัศมี 5 บล็อก (คูลดาวน์ 15 วินาที) |

## เริ่มเล่น

1. ขุด **แร่อาร์เคน** (สีม่วงเรืองแสง ใต้ดิน Y -60 ถึง 64) ด้วยอีเต้อ → ได้ **เศษผลึกอาร์เคน** 2-4 ชิ้น (Fortune ได้เพิ่ม, Silk Touch ได้ตัวแร่)
2. คราฟ **คทาเด็กฝึกเวท**: เศษผลึก 1 (มุมขวาบน) + ไม้ 2 (แนวทแยงลงซ้าย)
3. ถือคทาแล้วกดใช้ = ร่าย **ลูกศรเวท** (คาถาแรก) — ฆ่ามอนสเตอร์ได้ XP ของระบบเวท
4. เปิดคัมภีร์ → **คาถาทั้งหมด** → เรียนคาถาใหม่ด้วยเศษผลึก → ใส่ลงช่องคาถา 4 ช่อง
5. ทุกเลเวลได้ 3 แต้มค่าสถานะ → เปิดคัมภีร์ → **สถานะ** เพื่ออัป

## หินวาร์ป

- คราฟ: อิฐหิน 5 + เศษผลึก 3 + ไข่มุกเอนเดอร์ (BSB / SES / BBB) → วางแล้วตั้งชื่อ
- **แตะหินวาร์ป** ครั้งแรก = ค้นพบ, ครั้งต่อไป = เมนูวาร์ปไปหินวาร์ปที่รู้จัก (**ข้ามมิติได้**) ใช้มานา 20
- หินวาร์ปที่รู้จัก 6 ก้อนที่ใกล้ที่สุดจะขึ้นเป็นจุดสีม่วงบน **Locator Bar**
- เปิดจากคัมภีร์ → เครือข่ายหินวาร์ป ได้ทุกที่

## รอยแยกมิติ (ดันเจี้ยน)

1. คราฟ **กุญแจรอยแยก** (ไข่มุกเอนเดอร์ + แท่งอาร์เคน + แก่นแท้ความว่างเปล่า) แล้วกดใช้ → เลือกระดับ
2. **ประตูมิติหมุนวน** จะเปิดตรงหน้า (อยู่ 5 นาที) — **ทุกคนในปาร์ตี้เดินเข้าประตูเดียวกันได้**
3. ข้างในคือ **มิติใหม่ "The Rift"** (สร้างด้วย Script API) ดันเจี้ยนถูกสร้างสดตอนเปิด ไม่เหมือนกันสักครั้ง:
   - ผังเขาวงกต 4×4 = 16 ห้อง + ทางเดิน + ลานบอสทรงกลม
   - **ห้องต่อสู้**: เดินเข้าไปแล้ว **ประตูจะถูกผนึกด้วยกำแพงพลัง** มอนสเตอร์เกิดเป็นระลอก (ระดับ II/III มี 2 ระลอก) ฆ่าหมดประตูเปิด + รางวัล
   - **ห้องสมบัติ**: หีบสุ่มของตามระดับ (มีโอกาสได้รูน)
   - **แท่นฟื้นพลัง**: ยืนใกล้ ๆ ฟื้นเลือดและมานา
4. เคลียร์ห้องต่อสู้ครบ → กำแพงทางเดินหายไป → เข้าลานบอส → บอสปรากฏตัว
5. ชนะ → หีบรางวัลกลางลาน + **ประตูทางออก** (รอยแยกพังลงใน 2 นาที)

| ระดับ | เงื่อนไข | มอนสเตอร์ | บอส |
|---|---|---|---|
| I | Lv 1 | ซอมบี้, โครงกระดูก, แมงมุม, นักล่ารอยแยก, วิญญาณ | ผู้พิทักษ์ผลึก (โกเลมผลึกเสริมพลัง) |
| II | Lv 12 + ผ่าน I | + อิมพ์เพลิง, เบลซ, วิทเธอร์สเกเลตัน (แรงขึ้น+ทนขึ้น) | ยักษ์เพลิงโคลอสซัส |
| III | Lv 25 + ผ่าน II | + โกเลมผลึก, เอนเดอร์แมน, อีโวเกอร์ (แรงขึ้นอีก + เร็วขึ้น) | ไททันแห่งความว่างเปล่า |

- ตายในรอยแยก? เปิดคัมภีร์ → รอยแยกมิติ → **กลับเข้ารอยแยก** (ถ้ายังไม่พัง)
- ทุบบล็อกในรอยแยกไม่ได้ ระเบิดก็ไม่ทำลาย, ตกลงความว่างเปล่าจะถูกดึงกลับห้องแรก
- ปิดเกมระหว่างอยู่ในรอยแยก → รอยแยกจะพัง และส่งทุกคนกลับจุดที่เข้ามาตอนเข้าเกมครั้งต่อไป
- เข้าไปตอนดันเจี้ยนยังสร้างไม่เสร็จ จะขึ้น "รอยแยกกำลังก่อตัว..." และถูกตรึงไว้ที่จุดเกิดจนพื้นเสร็จ (ไม่ตก)
- ถ้ามิติใหม่ใช้ไม่ได้บนเครื่องนั้น ระบบจะคืนกุญแจและสร้างดันเจี้ยนบนท้องฟ้าเหนือจุดที่เปิดแทนอัตโนมัติ (ใช้ได้ในโลกปกติและ The End)
  สลับเองได้ที่ ผู้ดูแล → ตั้งค่าโลก → "สร้างดันเจี้ยนบนท้องฟ้าแทนมิติใหม่"

# Tiered Bundles — ถุงเก็บของ 5 ระดับ เปิดเป็นกล่องใหญ่ (Minecraft Bedrock / มือถือ)

ถุงคราฟจาก **หนังวัว** แล้วอัปเกรดได้ทีละขั้นด้วยแร่ ของข้างในย้ายตามไปถุงใหม่ทุกครั้ง
เปิดถุงแล้วได้หน้าต่าง **กล่องใหญ่ (กล่อง 2 กล่อง 54 ช่อง)** แถวล่างสุดเป็น **ปุ่มกระจกสี** สำหรับเปลี่ยนหน้า แบบเมนูของเซิร์ฟเวอร์

| ถุง | ระดับ | ช่องเก็บของ | จำนวนหน้า (หน้าละ 45 ช่อง) |
|---|---|---|---|
| **ถุงหนัง** (Leather Bundle) | 1 | 9 | 1 |
| **ถุงเหล็ก** (Iron Bundle) | 2 | 27 | 1 |
| **ถุงทอง** (Golden Bundle) | 3 | 54 | 2 (45 + 9) |
| **ถุงเพชร** (Diamond Bundle) | 4 | 108 | 3 (45 + 45 + 18) |
| **ถุงเนเทอไรท์** (Netherite Bundle) | 5 | 216 | 5 (45 × 4 + 36) — ไม่ไหม้ในลาวา |

ความจุครบตามตาราง แถวปุ่มไม่ได้กินช่อง (ใช้วิธีเพิ่มหน้าแทน)

## ติดตั้ง

1. เปิดไฟล์ `TieredBundles.mcaddon` ด้วย Minecraft
2. ตั้งค่าโลก → **Behavior Packs** → เปิด *Tiered Bundles* (Resource Pack จะเปิดตามให้เอง)
3. ไม่ต้องเปิด Experiments — ต้องใช้ Minecraft Bedrock **1.26.50 ขึ้นไป**

## สูตรคราฟ

**ถุงหนัง** — โต๊ะคราฟ ใช้หนังวัว (Leather) 5 ชิ้น
```
L . L      L = หนังวัว (Leather)
L L L
```

**อัปเกรด** — โต๊ะคราฟ วางแร่ 8 ชิ้นรอบ ๆ แล้ววางถุงขั้นก่อนหน้าไว้ตรงกลาง
```
M M M      ถุงหนัง  + แท่งเหล็ก 8  → ถุงเหล็ก
M B M      ถุงเหล็ก + แท่งทอง 8   → ถุงทอง
M M M      ถุงทอง   + เพชร 8      → ถุงเพชร
```

**ถุงเนเทอไรท์** — โต๊ะตีเหล็ก (Smithing Table) แบบอุปกรณ์เนเทอไรท์ทั่วไป:
Netherite Upgrade + ถุงเพชร + Netherite Ingot

> ของในถุงเดิมย้ายไปถุงใหม่อัตโนมัติ (ช่องเพิ่มขึ้น ของไม่หาย)

## วิธีใช้

- **ถือถุงไว้ในมือ แล้วแตะหน้าจอ / คลิกขวา** → เปิดหน้าต่างกล่องใหญ่
- ใส่/หยิบของได้เหมือนกล่องปกติ (แตะ, ลาก, Shift-คลิกได้หมด)
- แถวล่างสุด (ปุ่มกระจก):

| ช่อง | ปุ่ม | ใช้ทำอะไร |
|---|---|---|
| ซ้ายสุด | 🟥 กระจกแดง ◀ | ไปหน้าก่อนหน้า |
| ตรงกลาง | 🟦 กระจกฟ้า i | บอกหน้าปัจจุบัน / ความจุ |
| ขวาสุด | 🟩 กระจกเขียว ▶ | ไปหน้าถัดไป |
| ที่เหลือ | ⬛ กระจกดำ | ตกแต่ง |

- ช่องที่เกินความจุของหน้าสุดท้ายเป็น **กระจกเทา 🔒 ช่องล็อก** ใส่ของไม่ได้
- ปุ่มกระจกหยิบออกมาไม่ได้ (กดแล้วจะหายจากมือ/กระเป๋าเอง ทิ้งลงพื้นก็หาย)
- ใส่ถุงซ้อนในถุงไม่ได้ (เด้งกลับเข้ากระเป๋า กันถุงหายเข้าไปในตัวเอง)
- ของในถุงติดอยู่กับ **ตัวถุง** ไม่ใช่ตัวผู้เล่น: ทิ้งถุงให้เพื่อน เก็บใส่กล่อง หรือตายแล้วเก็บถุงคืน ของข้างในยังอยู่ครบ
- ข้อมูลไอเท็มเก็บครบทุกอย่าง (เอนชานท์, ชื่อ, ความทนทาน, กล่องชัลเกอร์ที่มีของข้างใน)

## หมายเหตุ

- ตอนถือถุง จะมีตัวเปิดถุงที่มองไม่เห็นลอยอยู่ตรงหน้า → แตะตรงไหนก็เปิดถุง
  จึง **วางบล็อก/ใช้ของไม่ได้ขณะถือถุง** (สลับไปถือของอื่นก่อน)
- หลังเข้าโลกรอ ~3 วินาทีก่อนเปิดถุงได้ (รอโลกโหลด)
- ถุงที่หน้าตาเหมือนกันแต่คนละใบ ของข้างในแยกกัน (แต่ละใบมีรหัสของตัวเอง)
- ถุงหนังของ addon นี้แยกจาก Bundle ของเกมเดิม (Bundle เดิมยังคราฟได้ตามปกติ)
- ใช้ `/give @s bt:bundle_netherite` ฯลฯ ในโหมดสร้างสรรค์ได้

## หลักการทำงาน

1. ถือถุง → สคริปต์สร้าง entity ล่องหน `bt:bag_ui` (กล่อง 54 ช่อง) ลอยหน้าผู้เล่น แตะแล้วเกมเปิดหน้าต่างกล่องใหญ่ให้
2. ของแต่ละหน้าเก็บใน entity `bt:bag_page` (45 ช่อง) ซ่อนไว้ใต้เพดานโลกตรงหัวผู้เล่น
3. กดปุ่มกระจก = ปุ่มหายจากช่อง → สคริปต์รู้ว่ากด ย้ายของหน้าเดิมกลับไป แล้วดึงของหน้าใหม่มาแสดง (หน้าต่างไม่ปิด)
4. เลิกถือถุง → บันทึกทุกหน้าเป็น **structure** ในไฟล์โลก (`bt:bag_<รหัสถุง>`) แล้วลบ entity ทิ้ง
5. ปิดเกมขณะถือถุง → entity ยังอยู่ในโลก ครั้งหน้าสคริปต์จะเก็บกลับเข้าถุงให้เอง
6. คราฟอัปเกรด → ถุงเก่าหายจากกระเป๋า ถุงใหม่ที่ได้มาจะรับรหัสของถุงเก่า (ของจึงตามมา)
