# Survival Flight — Addon บินได้ในโหมดเอาชีวิตรอด (Minecraft Bedrock / มือถือ)

ถือ **ขนนก (Feather)** แล้วกดใช้ เพื่อเปิด/ปิดการบินในโหมด Survival

## ขั้นตอนการติดตั้งบนมือถือ

1. ดาวน์โหลดไฟล์ `SurvivalFlight.mcaddon` ลงมือถือ
2. แตะเปิดไฟล์ → เลือกเปิดด้วย Minecraft → เกมจะขึ้นว่า "Import Started… / Successfully imported"
   - ถ้าแตะแล้วไม่ขึ้น (บาง iPhone): ใช้แอป Files → แชร์ → เลือก Minecraft
3. สร้างโลกใหม่ หรือแก้ไขโลกเดิม → **Behavior Packs** → **Available** → เลือก *Survival Flight* → **Activate**
4. (ไม่บังคับ แต่แนะนำ) **Game Settings → Cheats → เปิด Education Edition**
   เพื่อให้บินได้เหมือนโหมดสร้างสรรค์จริง ๆ
5. เข้าโลก หาขนนก (ฆ่าไก่) แล้วกดใช้

> ต้องใช้ Minecraft Bedrock เวอร์ชัน 1.21.90 ขึ้นไป ไม่ต้องเปิด Experiments ใด ๆ

## วิธีบิน

| การกระทำ | ผลลัพธ์ |
|---|---|
| ถือขนนก แล้วแตะค้าง (PC: คลิกขวา) | เปิด / ปิดการบิน |
| **เปิด Education Edition ไว้** | แตะปุ่มกระโดด 2 ครั้ง บินเหมือนโหมดสร้างสรรค์ |
| **ไม่ได้เปิด Education Edition** | กดกระโดดค้าง = บินขึ้น, กดย่อ = บินลง, ไม่กด = ลอยนิ่ง, จอยสติ๊ก = บินไปทางที่มอง, วิ่ง = บินเร็วขึ้น |

- ปิดการบินกลางอากาศจะได้ Slow Falling 5 วินาที ไม่ตกตาย
- สถานะการบินจะถูกจำไว้ ออกแล้วเข้าเกมใหม่/ตายแล้วเกิดใหม่ก็ยังบินได้

## โครงสร้างไฟล์

```
SurvivalFlight_BP/
├── manifest.json      ข้อมูล pack + ประกาศใช้ Script API (@minecraft/server 2.0.0)
├── pack_icon.png      ไอคอน
└── scripts/main.js    โค้ดการบินทั้งหมด
build.sh               แพ็กเป็น SurvivalFlight.mcaddon
```

## หลักการทำงาน (คิดทีละขั้น)

1. **เลือกวิธี** — Bedrock ไม่มีคำสั่งให้ Survival บินได้ตรง ๆ ยกเว้น `/ability mayfly`
   ซึ่งใช้ได้เฉพาะเมื่อเปิด Education Edition จึงทำ 2 โหมด
2. **ตรวจโหมด** — ตอนเปิดการบิน สคริปต์ลองรัน `ability @s mayfly true`
   ถ้าสำเร็จใช้โหมด Native ถ้าล้มเหลวใช้โหมด Scripted
3. **โหมด Scripted** — ทุก tick อ่านปุ่มกระโดด/ย่อ และจอยสติ๊ก (`inputInfo.getMovementVector()`)
   แปลงเป็นทิศตามมุมกล้อง แล้วตั้งความเร็วด้วย `applyKnockback()`
4. **กันตกตาย** — ใส่ Slow Falling แบบไม่มี particle ระหว่างบิน และหลังปิดการบิน
5. **จำสถานะ** — เก็บใน Dynamic Property ของผู้เล่น แล้วคืนค่าเมื่อเกิดใหม่

## ปรับแต่ง

แก้ค่าด้านบนของ `scripts/main.js` เช่น `TOGGLE_ITEM`, `FLY_SPEED`, `SPRINT_SPEED`, `VERTICAL_SPEED`
แล้วรัน `./build.sh` เพื่อสร้างไฟล์ `.mcaddon` ใหม่

# Smelted Ore Blocks — ขุดแร่ได้บล็อกแร่ที่เผาแล้ว (Minecraft Bedrock / มือถือ)

ขุดแร่ด้วยเครื่องมือที่ถูกต้อง แล้วจะได้ **บล็อก** ของแร่ที่เผาแล้วแทนของที่ดรอปตามปกติ

| แร่ (รวม Deepslate) | ได้ |
|---|---|
| แร่ถ่านหิน | บล็อกถ่านหิน |
| แร่เหล็ก | บล็อกเหล็ก |
| แร่ทองแดง | บล็อกทองแดง |
| แร่ทอง / แร่ทองเนเธอร์ | บล็อกทอง |
| แร่เรดสโตน | บล็อกเรดสโตน |
| แร่ลาพิส | บล็อกลาพิส |
| แร่เพชร | บล็อกเพชร |
| แร่มรกต | บล็อกมรกต |
| แร่ควอตซ์เนเธอร์ | บล็อกควอตซ์ |

## ติดตั้ง

1. ดาวน์โหลด `SmeltedOreBlocks.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *Smelted Ore Blocks* → **Activate**
3. เข้าโลกแล้วขุดแร่ได้เลย

> ต้องใช้ Minecraft Bedrock 1.21.90 ขึ้นไป ไม่ต้องเปิด Experiments

## รายละเอียด

- ยังต้องใช้เครื่องมือที่ถูกต้องเหมือนเดิม (เช่น แร่เพชรต้องใช้อีเตอร์เหล็กขึ้นไป) ใช้ผิดจะไม่ได้อะไร
- ยังได้ XP และเครื่องมือยังสึกตามปกติ
- ขุดด้วย **Silk Touch** ยังได้ตัวแร่เหมือนเดิม
- Fortune ไม่มีผล ได้ 1 บล็อกต่อแร่ 1 ก้อน
- โหมดสร้างสรรค์จะไม่ดรอปอะไร

## ปรับแต่ง

แก้ค่าด้านบนของ `SmeltedOreBlocks_BP/scripts/main.js`:
`ORE_TO_BLOCK` (แร่ → บล็อกที่ได้), `BLOCKS_PER_ORE`, `KEEP_SILK_TOUCH`
แล้วรัน `./build.sh` เพื่อสร้าง `.mcaddon` ใหม่

# Gear Effects — สวมเกราะ / ถือไอเท็ม แล้วได้เอฟเฟกต์ (Minecraft Bedrock / มือถือ)

## ติดตั้ง

1. ดาวน์โหลด `GearEffects.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *Gear Effects* → **Activate**

> ต้องใช้ Minecraft Bedrock 1.21.90 ขึ้นไป ไม่ต้องเปิด Experiments

## เซ็ตเกราะ (นับชิ้นที่เป็นวัสดุเดียวกัน)

| เกราะ | ใส่ 2 ชิ้นขึ้นไป | ใส่ครบ 4 ชิ้น |
|---|---|---|
| หนัง | ความเร็ว I | + กระโดดสูง I |
| โซ่ | ความเร็ว I | + ขุดเร็ว I |
| ทองแดง | ขุดเร็ว I | + ต้านทาน I |
| ทอง | ขุดเร็ว I | + ฟื้นฟูเลือด I |
| เหล็ก | ต้านทาน I | + พลังโจมตี I |
| เพชร | ต้านทาน I | + พลังโจมตี I, ฟื้นฟูเลือด I |
| เนเธอไรต์ | ต้านทาน I, กันไฟ | ต้านทาน II, พลังโจมตี II, ฟื้นฟูเลือด I, กันไฟ |
| หมวกกระดองเต่า (1 ชิ้น) | หายใจใต้น้ำ, มองในที่มืด | |

## ไอเท็มในมือ (มือหลักหรือมือรอง)

| ไอเท็ม | เอฟเฟกต์ |
|---|---|
| ดาบ, ขวาน | พลังโจมตี I (เพชร/เนเธอไรต์ = II) |
| อีเตอร์, พลั่ว, จอบ | ขุดเร็ว I (เพชร/เนเธอไรต์ = II) |
| ธนู, หน้าไม้, น้ำตาล | ความเร็ว I |
| ตรีศูล, หัวใจแห่งท้องทะเล | พลังคอนดูอิต |
| กระบอง (Mace) | กระโดดสูง II |
| เท้ากระต่าย | กระโดดสูง I |
| โล่ | ต้านทาน I |
| เบ็ดตกปลา, เปลือกหอยนอติลุส | หายใจใต้น้ำ |
| คบเพลิง, ตะเกียง, กล้องส่องทางไกล, ตาเอนเดอร์ | มองในที่มืด |
| ขนนก | ตกช้า |
| แท่งเบลซ, ครีมแมกมา | กันไฟ |
| โทเท็มแห่งความเป็นอมตะ, แตงโมทอง | ฟื้นฟูเลือด I |

- ถ้าได้เอฟเฟกต์เดียวกันจากหลายแหล่ง จะใช้ระดับที่สูงที่สุด
- ถอดเกราะ / เปลี่ยนของในมือ เอฟเฟกต์จะหายภายใน 1 วินาที
- ไม่ลบเอฟเฟกต์จากยาหรือบีคอนที่แรงกว่าหรือนานกว่า
- เมื่อเอฟเฟกต์เปลี่ยนจะมีข้อความบอกเหนือแถบไอเท็ม

## ปรับแต่ง

# Sword Sweep — ดาบตีกวาดเหมือน PC (Minecraft Bedrock / มือถือ)

ถือดาบแล้ว**แตะตี**ตรงไหนก็ได้ ระบบจะกวาดฟันศัตรูทุกตัวที่อยู่ข้างหน้าเป็นรูปพัด **ไม่ต้องเล็งให้โดนตัว**
และยังใช้ดาบขุด/ทุบบล็อกได้ตามปกติ

## ติดตั้ง

1. ดาวน์โหลด `SwordSweep.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *Sword Sweep* → **Activate**
3. เข้าโลก ถือดาบ แล้วแตะจอตีได้เลย

> ต้องใช้ Minecraft Bedrock **1.26.10 ขึ้นไป** (ใช้ Script API `@minecraft/server` 2.5.0) ไม่ต้องเปิด Experiments

## การทำงาน

| การกระทำ | ผลลัพธ์ |
|---|---|
| แตะตีอากาศ (ไม่โดนอะไร) | กวาดข้างหน้า: ตัวที่อยู่ตรงหน้าที่สุดโดนดาเมจเต็ม ตัวอื่นโดนดาเมจกวาด |
| แตะตีโดนมอนตรง ๆ | ตัวที่โดนรับดาเมจปกติจากเกม ตัวรอบ ๆ โดนดาเมจกวาด |
| แตะค้าง / ขุดบล็อก | ขุดบล็อกตามปกติ ไม่กวาด |
| หันไปมองบล็อกที่อยู่ใกล้กว่ามอน แล้วแตะ | ถือว่ากำลังขุด ไม่กวาด |

- ระยะกวาด 3.5 บล็อก กว้าง 140° ข้างหน้า ตีทะลุกำแพงไม่ได้
- ดาเมจคิดจากชนิดดาบ + Sharpness + ยาพลังโจมตี/อ่อนแรง และ Fire Aspect ทำให้ไฟติด
- ดาเมจกวาด = 1 + 50% ของดาเมจดาบ (PC ได้แค่ 1 ถ้าไม่มี Sweeping Edge ซึ่ง Bedrock ไม่มีเอนชานต์นี้)
- กวาดได้ทุก 0.6 วินาที ใกล้กับความเร็วดาบใน PC
- ไม่โดนผู้เล่นคนอื่น, สัตว์เลี้ยงของตัวเอง, ไอเท็ม, อาร์เมอร์สแตนด์
- ใช้ได้กับดาบทุกชนิด รวมถึงดาบจาก addon อื่นที่ชื่อลงท้ายด้วย `_sword` หรือมี tag `minecraft:is_sword`
- ดาบสึกเพิ่ม 1 เมื่อกวาดโดนศัตรูโดยไม่ได้ตีโดนตรง ๆ (คิด Unbreaking ด้วย ไม่สึกในโหมดสร้างสรรค์)

## ปรับแต่ง

แก้ค่าด้านบนของ `SwordSweep_BP/scripts/main.js`:
`SWEEP_RANGE`, `SWEEP_HALF_ANGLE`, `SWEEP_DAMAGE_RATIO`, `COOLDOWN_TICKS`, `KNOCKBACK`, `HIT_PLAYERS`, `HIT_OWN_PETS`, `SWORD_DAMAGE`
แล้วรัน `./build.sh` เพื่อสร้าง `.mcaddon` ใหม่

# RPG Levels — ระบบเลเวลตัวละครแบบละเอียด (Minecraft Bedrock / มือถือ)

ระบบ RPG เต็มรูปแบบ: **เลเวลตัวละคร 1–100**, **ค่าสถานะ 6 ตัว**, **ความชำนาญอาวุธ/อุปกรณ์ 8 ชนิด** (ถึงขั้นได้เอฟเฟกต์พิเศษ)
และ **สกิลพิเศษ 20 สกิล** ที่ปลดล็อกตามเลเวล แล้ว **เปิด/ปิดเองได้** เช่น บินได้ แม่เหล็ก ขุดแร่ทั้งสาย ตัดต้นไม้ทั้งต้น มองในที่มืด กันไฟ

## ติดตั้ง

1. ดาวน์โหลด `RPGLevels.mcaddon` ลงมือถือ แล้วแตะเปิดด้วย Minecraft (มีทั้ง Behavior + Resource pack ในไฟล์เดียว)
2. ตั้งค่าโลก → **Behavior Packs** → **Available** → *RPG Levels* → **Activate** (Resource pack จะเปิดให้อัตโนมัติ)
3. (แนะนำ) **Game Settings → Cheats → เปิด Education Edition** เพื่อให้สกิลบินได้เหมือนโหมดสร้างสรรค์
4. เข้าโลก จะได้ **สมุดสถานะ RPG** ฟรี → ถือแล้วแตะใช้ (PC: คลิกขวา) เพื่อเปิดเมนู

> ต้องใช้ Minecraft Bedrock 1.21.90 ขึ้นไป ไม่ต้องเปิด Experiments
> ไม่ควรเปิดคู่กับ *Survival Flight* (ทั้งคู่คุมการบินเหมือนกัน)

## เมนูสมุดสถานะ

| ปุ่ม | ทำอะไร |
|---|---|
| ข้อมูลตัวละคร | ดูค่าสถานะ + ผลที่ได้จริง (ดาเมจ, % หลบ, % คริ ฯลฯ), ความชำนาญ, สกิลที่เปิดอยู่ |
| อัพค่าสถานะ | ใช้แต้มอัพ STR / VIT / DEF / AGI / DEX / LUK (เลื่อนแถบเลือกจำนวน) และรีเซ็ตแต้ม (ใช้ 10 เลเวล XP) |
| ความชำนาญอาวุธ/อุปกรณ์ | ดูเลเวลและเอฟเฟกต์ที่ปลดล็อกของอุปกรณ์แต่ละชนิด |
| สกิลพิเศษ | แตะเพื่อเปิด/ปิดทีละสกิล หรือเปิด/ปิดทั้งหมด |
| ตั้งค่า | แถบ XP, ขุดแร่/ตัดไม้ต้องย่อตัวไหม, ทำลายใบไม้ไหม, ระยะแม่เหล็ก |
| ผู้ดูแลโลก | (เฉพาะคนแรกที่เข้าโลก หรือมีแท็ก `rpg_admin`) ตัวคูณ XP, โชว์เลเวลเหนือชื่อ, ตั้งเลเวล/ล้างข้อมูลผู้เล่น |

สมุดหาย → คราฟใหม่: **หนังสือ + ลาพิส ลาซูลี** (ไม่มีรูปแบบ)

## เลเวลตัวละคร

- รับ XP จาก: ฆ่ามอน (ซอมบี้ 15, เอนเดอร์แมน 30, วอร์เดน 500, มังกร 3000), ขุดแร่ (เพชร 25, เศษโบราณ 50), ตัดไม้ 2, เก็บพืชที่โตแล้ว 3, ขุดบล็อกทั่วไป 0.3
- เลเวลอัพได้ **3 แต้มสถานะ** และทุก 10 เลเวลได้เพิ่มอีก **5 แต้ม**
- มีฉายาตามเลเวล (มือใหม่ → นักผจญภัย → นักรบ → ผู้กล้า → ยอดฝีมือ → ปรมาจารย์ → ตำนาน → เทพเจ้า) และโชว์ `[Lv.xx]` เหนือชื่อ
- ตายไม่เสียเลเวล ข้อมูลเก็บในตัวผู้เล่น (ออก-เข้าเกมใหม่ยังอยู่)

## ค่าสถานะ (สูงสุดตัวละ 100)

| ค่าสถานะ | ผล |
|---|---|
| STR พลังโจมตี | ดาเมจระยะประชิด +0.2 ต่อแต้ม |
| VIT พลังชีวิต | ทุก 10 แต้ม เลือดสูงสุด +2 หัวใจ (สูงสุด +20 หัวใจ) และฟื้นเลือดเอง |
| DEF ป้องกัน | ลดดาเมจที่ได้รับ 0.5% ต่อแต้ม (สูงสุด 50%) |
| AGI ความว่องไว | หลบการโจมตี 0.25% ต่อแต้ม, ทุก 30 แต้มได้ Speed +1 ระดับ, บินเร็วขึ้น |

## หมายเหตุ

- ขุดแร่ทั้งสาย / ตัดต้นไม้ทั้งต้น ทำให้เครื่องมือสึกตามจำนวนบล็อก (คิด Unbreaking) และ**หยุดเองก่อนเครื่องมือพัง**
- เอฟเฟกต์จากยา/บีคอนที่แรงกว่าจะไม่ถูกทับ
- โหมดสร้างสรรค์จะไม่ได้ XP จากการขุด
- คำสั่ง (ต้องเปิดโกง): `/scriptevent rpg:menu`, `/scriptevent rpg:book`,
  ผู้ดูแล: `/scriptevent rpg:xp 500`, `/scriptevent rpg:level 30`

## ปรับแต่ง

ค่าทั้งหมดอยู่ใน `RPGLevels_BP/scripts/config.js` เช่น สูตร XP (`xpToNext`), XP มอน/แร่ (`MOB_XP`, `ORE_XP`),
ผลของค่าสถานะ (`statFx`), เลเวลปลดล็อกสกิล (`SKILLS`), ขีดจำกัด (`veinLimit`, `treeLimit`, `magnetRange`)
แล้วรัน `./build.sh` เพื่อสร้าง `RPGLevels.mcaddon` ใหม่

| ไฟล์ | หน้าที่ |
|---|---|
| `main.js` | เริ่มระบบ, แจกสมุด, เปิดเมนู, คำสั่ง scriptevent |
| `config.js` | ตัวเลขและตารางทั้งหมด |
| `data.js` | บันทึก/โหลดข้อมูลผู้เล่น (Dynamic Property) |
| `progression.js` | XP, เลเวลอัพ, ความชำนาญ, แถบ XP |
| `combat.js` | ดาเมจเพิ่ม, คริ, หลบ, ลดดาเมจ, เอฟเฟกต์อาวุธ/เกราะ, XP จากการฆ่า |
| `gathering.js` | ขุดแร่ทั้งสาย, ตัดต้นไม้, เกษตร, พลั่ว 3x3, ดรอปคู่/หลอมแร่ |
| `effects.js` | เอฟเฟกต์สกิล, บิน, แม่เหล็ก, ร่อนลง, เร่งพืช |
| `ui.js` | เมนูทั้งหมด |
